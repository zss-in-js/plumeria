## Nesting
A style nests one level of selectors, and only in one direction:

- A query (`@media` or `@container`) can hold a pseudo-selector.
- A pseudo-selector cannot hold a query, and a query cannot hold another query.
- A pseudo-selector cannot hold another pseudo-selector. Write the pair as one key, such as `':hover::before'`.

```ts title="TypeScript" {1}
import * as css from '@plumeria/core';

const styles = css.create({
  list: {
    '@media (max-width: 768px)': { // [!code ++]
      ':hover': { // [!code ++]
        listStyleType: 'none', // [!code ++]
      }, // [!code ++]
    }, // [!code ++]
  },
});
```

Not allowed:

```ts title="TypeScript" {1}
import * as css from '@plumeria/core';

const styles = css.create({
  list: {
    ':hover': {
      '@media (max-width: 768px)': { // [!code --]
        background: 'skyblue', // [!code --]
      }, // [!code --]
    },
  },
});
```

## Combinators
A key cannot contain a combinator (`>`, `+`, `~` or a space) except inside a functional pseudo-class such as `:has()`. To style a child from its parent's state, use [marker and extended](/docs/api-reference/javascript/marker).

`no-invalid-selector` and `no-combinator` in [`@plumeria/eslint-plugin`](/docs/api-reference/plugins/eslint-plugin) report each of these.

## Functional pseudo-classes
A functional pseudo-class cannot appear inside another one of the same name, at any depth. Different names can nest, such as `':is(:where(:not(:has(.a))))'`.

```ts
':where(:where(.a, .b), .c)' // [!code --]
':where(.a, .b, .c)' // [!code ++]
':is(:where(:is(.a)))' // [!code --]
':not(:not(.a), .b)' // [!code --]
```

The compiler stops the build on such a key. `no-invalid-selector` flattens it with a fix when the nested call is a whole argument, as in the first line; any other shape, and every `:not()` or `:has()`, has to be rewritten by hand, because flattening would change what the selector matches.

## Reason
This design intentionally avoids reverse nesting.

- Type system limitations (recursive types)
- Avoiding reverse nesting complexity
- Ensuring consistent nesting patterns
