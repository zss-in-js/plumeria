## classStyle snippet
In VS Code, add a snippet that expands `class` into `classStyle={}`.  
`shift + command + p >`  
`select >` Snippets: Configure Snippets  
`select >` typescriptreact.json (TypeScript JSX) or javascriptreact.json (JavaScript JSX)  

```json title="typescriptreact.json"
{
  "classStyle": {
    "prefix": "class",
    "body": "classStyle={$1}",
    "description": "Plumeria classStyle",
  }
}
```

This setting makes the snippet appear at the top of the suggestions.
```json title="settings.json"
{
  // ...other settings
  "editor.snippetSuggestions": "top",
  // ...
}
```


### Usage
```jsx
<div class /> -> Enter -> <div classStyle={|} />
```
</Step>
<Step>
## ESLint

[`@plumeria/eslint-plugin`](/docs/api-reference/plugins/eslint-plugin) reports style problems as you type, once your editor's ESLint extension is on.
Set it up with the config in [Installation](/docs/installation#eslint-setup); the [plugin reference](/docs/api-reference/plugins/eslint-plugin) lists every rule.
</Step>
<Step>
<Callout title="Jump to definition">
  `Cmd` + click (macOS) or `Ctrl` + click (Windows, Linux) jumps from a style to its definition, even outside JSX.
</Callout>
