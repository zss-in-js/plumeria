---
title: 'css.use / classStyle'
description: 'Attach styles as a prop in JSX, or as a class name string anywhere else.'
---
To apply styles defined in Plumeria to a component, use the `classStyle` prop or the `css.use()` function.

## classStyle
```ts
type Style = StyleList<StyleNamespace>;

declare global {
  namespace React {
    interface HTMLAttributes<T> {
      classStyle?: Style;
    }
  }
}

export type { Style };
```

`classStyle` is a special prop for applying styles to components such as React. It is converted to `className` by the plugin at build time.

### Features
- Accepts a single style, or an array of styles. Arrays can be nested.
- Ignores `false`, `null`, and `undefined` wherever a style is accepted, which is what makes inline conditional branching work.
- Within an array, a later style takes precedence over an earlier one.

### Example

```tsx
import * as css from '@plumeria/core';

const styles = css.create({
  base: { color: 'red' },
  active: { fontWeight: 'bold' }
});

function Component({ active }) {
  return (
    <div classStyle={[styles.base, active && styles.active]}>
      Hello
    </div>
  );
}
```

## css.use()
```ts
export type use = (...rules: Style[]) => string;
export const use: use;
```
`css.use()` converts styles into a string of class names. Use it where the `classStyle` prop is not available, for example when passing a class name to an external component that only accepts `className`.

### Example

```ts
import * as css from '@plumeria/core';

const styles = css.create({
  text: { fontSize: '16px' }
});

// Get the class name as a string
const className = css.use(styles.text);

// Apply to an external component
<ExternalComponent className={css.use(styles.text)} />
```

<Callout title="Build time compiles">
`classStyle` and `css.use()` are both processed by the plugin at build time. There is zero runtime overhead, and the final bundle will only contain the class name as a string.
</Callout>
