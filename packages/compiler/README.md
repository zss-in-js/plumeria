# @plumeria/compiler

The SWC-based compiler that sweeps a project and extracts its CSS in one pass. [`@plumeria/turbopack-loader`](https://www.npmjs.com/package/@plumeria/turbopack-loader) installs it to build the stylesheet a Next.js production build needs on disk before any module is processed; it is not installed on its own.

If you are looking for Plumeria itself, start at [`@plumeria/core`](https://www.npmjs.com/package/@plumeria/core), and set your build up with [`@plumeria/next-plugin`](https://www.npmjs.com/package/@plumeria/next-plugin) or [`@plumeria/unplugin`](https://www.npmjs.com/package/@plumeria/unplugin).
