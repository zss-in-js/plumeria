# @plumeria/utils

Internal helpers shared by [`@plumeria/compiler`](https://www.npmjs.com/package/@plumeria/compiler), [`@plumeria/unplugin`](https://www.npmjs.com/package/@plumeria/unplugin) and [`@plumeria/turbopack-loader`](https://www.npmjs.com/package/@plumeria/turbopack-loader). It is installed as their dependency, not on its own.

If you are looking for Plumeria itself, start at [`@plumeria/core`](https://www.npmjs.com/package/@plumeria/core).

## API Stability

**Stability: Internal** — not a public API; it may change in any release.
See [API Stability](https://github.com/zss-in-js/plumeria#api-stability).
